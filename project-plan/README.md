# Sito Laurea Mariagrazia

## Struttura
- index.html
- styles.css
- images/
  - foto-01.jpg
  - foto-02.jpg
  - ...
  - foto-06.jpg

## Come usarlo
1. Crea una cartella `images`.
2. Inserisci le foto e rinominale `foto-01.jpg`, `foto-02.jpg`, ecc.
3. In `index.html`, sostituisci `https://example.com` con il link dell'album completo.
4. Se vuoi usare Adobe Fonts, crea un Web Project su Adobe Fonts e sostituisci `YOUR_KIT_ID`.
5. Carica tutto in un repository GitHub.
6. Vai in Settings → Pages → Deploy from a branch → `main` / root.
7. Usa l'URL GitHub Pages nel QR code.

## Privacy
Nel file è presente:
`<meta name="robots" content="noindex,nofollow,noarchive">`

Questo scoraggia l'indicizzazione da parte dei motori di ricerca, ma non rende il sito realmente privato.
Chiunque abbia il link può aprirlo.

Per maggiore riservatezza:
- usa un nome repository/URL non facilmente intuibile;
- non pubblicare il link altrove;
- se le foto sono sensibili, valuta un album con accesso controllato.
